# Samira Habib Bushra — Portfolio

A single-page portfolio site (`index.html`). The photo is embedded directly in the file, so there are no other assets to track.

## Publish with GitHub Pages

1. Create a new repository on GitHub (e.g. `samira-portfolio`).
2. Upload `index.html` to the root of the repo (drag-and-drop on the GitHub web UI works, or `git add index.html && git commit -m "Add portfolio" && git push`).
3. Go to **Settings → Pages**.
4. Under **Source**, select the `main` branch and `/ (root)` folder, then **Save**.
5. GitHub will publish it at `https://<your-username>.github.io/<repo-name>/` within a minute or two.

That's it — no build step, no dependencies.
